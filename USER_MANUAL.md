# User Manual - Obligations & Contracts Learning Hub

## Overview
This user manual provides step-by-step guidance on how to navigate and use the features in the Obligations & Contracts Learning Hub.

## Sections
1. **Navigating Tabs:** Click on top navigation buttons to switch between Lessons, Flashcards, Contract Validator, Quiz, and Saved Reviewer.
2. **Filtering Content:** Use the search bar or category drop-down to filter specific Civil Code articles.
3. **Saving Reviewers:** Click the star (★ Save) button on any card to store it in your browser's local storage for later review.
4. **Validating Contracts:** In the Validator tool, select contract attributes to determine legal status under Philippine Civil Law.
